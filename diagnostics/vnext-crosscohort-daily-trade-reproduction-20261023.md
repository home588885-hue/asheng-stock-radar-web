## 狀態閘門與限制

1. 歷史資料和延後2日參數已在多輪研究中被看到，**不能稱為真正 untouched holdout**；2026只是現有追溯資料，而且只覆蓋當初研究股票組，非整體上市櫃。
2. 個股股票除權息採 FinMind 參考價近似而非完整券商配息與稅務帳，無法驗證真實滑價及跌停無法成交。
3. 回測的 `dd_realized_pct` 僅為**平倉後實現損益回撤**，非每日日終持倉市值最大回撤；不能以它宣稱帳戶實際最大回撤。
4. 資金限制模擬從次日以後方回收退出現金，避免當日先花賣出款；股市T+2真實帳戶買賣可用額仍需以券商標準驗證。
5. 年度正負與整體正報酬對研究決策有參考價值，然而策略相較長期持有大盤ETF的報酬與風險仍未完成嚴格比較。
6. **正式部署閘門仍不通過**。只可在獨立研究做紙上驗證；不得自行開綠色正式買點或刪除既有股票追蹤。
7. 不新增 UI、按鈕、區塊、掃描次數、雲端定時工作；不動正式 `main` 或 Supabase live Edge Functions。

真正可重跑離線引擎、7項測試與完整參數矩陣已在聊天當次 sandbox 檔案 `asheng_vnext_research_reproducible_20261023.zip` 交付，**不包含使用者私有研究訊號原檔**。本公有 GitHub 只保留匿名統計與方法。
