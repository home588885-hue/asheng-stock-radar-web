# asheng-stock-radar-web

阿勝底部起漲雷達的獨立 GitHub Pages 前台，連接既有 Supabase。

- 管理員：`admin.html`，使用現有 Supabase 管理員帳號。
- 會員：`member.html`，使用現有會員帳號與權限。
- 前台來源：既有 `asheng-radar-member-web` v167 / member-v165，包含既有管理員會員管理與持股 API。
- 持股資料、MA10／MA20／MA60 選股模型、房產同步及 LINE 均不由此專案部署。
- 不含管理員持股識別碼、service-role 金鑰或會員資料。
- Supabase SDK 固定為 2.117.3。
