## 可重現 SQL 範本

```sql
-- 只讀：同一研究 run、同一期間比較，不混算其他 run。
SELECT
  family,
  CASE WHEN signal_date < DATE '2025-01-01' THEN '2022-24' ELSE '2025-26' END AS period,
  COUNT(*) AS n,
  ROUND(AVG(r20),2) AS avg_r20,
  ROUND(100.0*AVG((r20>0)::int),1) AS win20_pct,
  ROUND(AVG(mae10),2) AS avg_mae10
FROM public.spring_swallow_v5_research_events
WHERE run_id='86c2305a-3b60-493c-9ec8-2addbf754e78'
AND family IN ('FIRST_BREAKOUT','PULLBACK_REBREAK')
AND r20 IS NOT NULL
GROUP BY 1,2 ORDER BY 1,2;
```
